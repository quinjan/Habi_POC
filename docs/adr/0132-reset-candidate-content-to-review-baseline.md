# Reset Candidate Content To Review Baseline

Candidate Detail will offer a confirmation-protected `Reset candidate` action before the Review Batch becomes terminal. It restores the Candidate Review Baseline: proposed Material, Service, and external Provider names and Project Memory matches; Provider State; commercial fields; original GPT-5.5 category suggestions and their derived new-versus-existing gate state; original annotation proposals; confidence; and other candidate-local proposed fields. It removes reviewer content edits, changed Memory-Aware Name selections, reviewer-added or edited annotations, taxonomy drafts, and current accepted-gate changes while retaining superseded Taxonomy Decision history.

Reset never changes immutable Observed Name Text, Observed Provider Text, source excerpts, evidence ranges, duplicate-group membership, include-or-exclude outcome, other candidates, or historical audit entries. It is unavailable after import or another terminal Review Batch state and does not call AI again. The action is named `Reset candidate`, not `Reset to default`, because Defaulted Field State already means a value supplied by a project or POC default rather than the candidate's original review state.
