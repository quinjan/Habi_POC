# Project-Scoped Memory Context For AI Extraction

Each AI Extraction request may receive bounded active Project Memory from only the selected Project Workspace: resolved taxonomy paths, active Material and Service names with categories, and active Provider names with their categories and observed roles. It excludes prices, quantities, dates, and raw evidence text. A deterministic cap of 100 active Materials, 100 Services, and 100 Providers bounds the context; entries are ranked by normalized source-token overlap with stable name ordering as a tiebreaker, and Processing Job diagnostics disclose when entries were omitted. This context guides classification and candidate proposals, but source evidence, reviewer approval, and backend exact-name matching remain authoritative. No cross-project or company-wide memory is supplied in the POC, preserving Project Workspace isolation.
