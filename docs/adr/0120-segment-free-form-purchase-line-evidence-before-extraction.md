# Segment Free-Form Purchase Line Evidence Before Extraction

Free-form AI Extraction will first use a source-only AI pass to select exact, source-ordered Purchase Line Evidence Span excerpts without Project Memory, taxonomy, or candidate extraction context. It may also select exact Purchase Line Supporting Spans for shared headings or qualifiers and link them to multiple primary spans; extraction for a candidate receives its primary span and linked supporting spans, but never another candidate's primary span. Habi, rather than the AI, derives character ranges from all excerpts and accepts only ranges that reproduce the preserved Manual Source Entry exactly; each verified span set is then extracted independently, and every proposed fact must cite the particular primary or supporting span that grounds it. This supersedes ADR 0085's whole-entry evidence approach because candidate-local evidence reduces cross-line contamination without discarding shared source context, while retaining AI boundary judgment for free-form construction text and deterministic backend authority over offsets and source fidelity.

Segmentation favors recall over precision: it should retain every plausible Purchase Line Evidence Span because later candidate-local extraction and deterministic validation can reject an unsupported proposal, while an omitted span cannot be recovered downstream. Model allocation remains scorecard-driven under ADR 0078: a stronger model may be used for segmentation when it materially reduces omissions, while candidate-local extraction may use the cheaper model with targeted stronger-model retries for validation failures.

Segmentation is an atomic completeness boundary. If any proposed excerpt cannot be grounded exactly, primary spans overlap, supporting-span links are invalid, or another segmentation invariant fails, Habi rejects the complete segmentation result and retries the original source-only pass once with the configured stronger model. A second invalid result fails the Processing Job with compact diagnostics and creates no partial Review Batch; this deliberately narrows ADR 0092 because retaining only structurally valid segments could silently hide a Purchase Line before independent candidate extraction begins. Once segmentation is valid, a later failure isolated to one candidate span does not invalidate independently extracted candidates.
