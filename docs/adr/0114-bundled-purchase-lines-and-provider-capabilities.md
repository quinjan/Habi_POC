# Bundled Purchase Lines And Provider Capabilities

Habi will preserve source-backed supply-and-install work as one Bundled Purchase Line with one commercial quantity and combined price, linked to exactly one explicitly reviewed Material and one explicitly reviewed Service Memory Record that each retain their own Resolved Category Path. An external Provider is one project-scoped record with its own reviewer-confirmed Provider category; its visible material-supplier, service-provider, and supply-and-install roles are derived from active linked Purchase Lines. A known External or Internal Provider State on a Bundled Purchase Line automatically contributes all three line-level roles; Internal roles are never promoted to a Provider Memory Record and Unknown Providers have no role. Review resolves each distinct new Material, Service, and Provider category path independently, while reusing a decision for repeated paths; a new Provider with no confident specific category proposes `Providers / General`. Migration converts each existing single-concept Purchase Line into one Purchase Line Concept Link and derives displayed categories from linked Memory Records. It also moves existing external Providers from inherited Material or Service categories to each Project Workspace's neutral `Providers / General` category. This avoids inventing split commercial facts or duplicate Providers while keeping reusable concepts, observed capabilities, and evidence traceable.
