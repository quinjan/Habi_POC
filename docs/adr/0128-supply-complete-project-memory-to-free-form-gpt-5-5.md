# Supply Complete Project Memory To Free-Form GPT-5.5

The GPT-5.5 free-form request will receive all active Material, Service, and Provider names from only the selected Project Workspace together with their resolved category paths and Provider roles. It will not lexically rank, filter, or silently cap those records, and it will continue to exclude prior prices, quantities, dates, and raw evidence text. Exact candidate source grounding remains authoritative, so complete memory context may guide semantic normalization, matching, and taxonomy without becoming evidence for a source fact.

This supersedes ADR 0115's 100-record-per-type caps and source-token ranking only for GPT-5.5 free-form Manual Source Entry extraction; XLSX and other paths retain their existing context policy. Habi records supplied record counts and estimated input size in compact diagnostics. If the complete selected-project context cannot fit within the configured safe request budget, Habi fails before calling the model and says that no candidates were saved rather than silently degrading extraction with omitted Project Memory; retrieval or another scaling strategy is deferred until a real project requires it.
