# Source-Grounded Evidence Annotation Proposals Across Inputs

Habi will normalize Structured Manual Source Entry, free-form Manual Source Entry, and XLSX annotations into one candidate-level proposal contract whose text, Evidence Annotation Type, and target Memory Record require reviewer approval before import. Explicit structured annotations and recognized XLSX columns are grounded deterministically, legacy remarks become Purchase Line general qualifiers, free-form AI proposals require exact source excerpts and character spans, and AI-classified XLSX annotations are limited to fallback rows with exact cell grounding so they cannot replace deterministic source facts. Each imported Evidence Annotation preserves its final reviewed text, type, and target together with its immutable source excerpt and annotation-specific locator; inference provenance is visible during review, while confidence remains candidate-level under ADR-0091.
