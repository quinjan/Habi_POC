# Use Creatable Memory-Aware Name Controls

Candidate Detail will review each Material, Service, and external Provider name through a searchable, creatable combobox rather than an unconstrained text input or closed dropdown. The options are active same-type Memory Records from the selected Project Workspace and are keyed by explicit record ID; choosing one sets the reviewed name and Project Memory match to that record, while a non-matching free-text value represents a new record with no match. Typing an existing option's exact normalized name automatically resolves to that record rather than creating a duplicate, preserving ADR 0016; a genuinely distinct record must use a distinct reviewed name. GPT-5.5's Proposed Project Memory Match is preselected when valid, and the immutable Observed Name Text or Observed Provider Text remains visible beneath the control so normalization is auditable without making source wording editable.

This replaces stale-match recomputation through arbitrary text editing with an explicit review choice between an existing record and a new name. Internal and Unknown Provider States hide the Provider name control and retain null Provider name and match values.

Selecting an existing option makes its inherited category read-only and creates no Taxonomy Gate under ADR 0131. The reviewer must clear the corresponding Material, Service, or external Provider control before taxonomy becomes editable; selecting an existing option again restores its category and no-gate state, while unmatched free text creates a new-record Taxonomy Gate.

Each Material or Service option displays its current Resolved Category Path beneath the name. Each external Provider option displays its Provider category and current derived Provider Roles. The selector does not expose prior prices, quantities, dates, or evidence excerpts, preserving ADR 0115's boundary between reusable identity context and prior commercial facts even though ADR 0128 supplies the complete active vocabulary to GPT-5.5.
