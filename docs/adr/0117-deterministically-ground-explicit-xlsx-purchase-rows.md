# Deterministically Ground Explicit XLSX Purchase Rows

After AI profiles a worksheet under ADR 0113, Habi will deterministically enrich exact column mappings from visible header text and will create source-grounded candidates for body rows that explicitly provide a recognizable Purchase Line kind, the required Material or Service names, and complete source category paths. A source-grounded row replaces any AI candidate for the same primary body row; AI Extraction remains the fallback for incomplete or ambiguous rows.

For a source-grounded row, the source Line kind determines whether the Purchase Line is Material-only, Service-only, or Bundled. Bundled rows retain one shared commercial quantity and combined or total price under ADR 0114, while unit price remains separate profile context. Explicit Provider State, Provider name, and Provider category columns are authoritative. Contractor Assigned may classify an already source-backed exact provider-name match as Internal under ADR 0116, but neither AI nor deterministic normalization may substitute Contractor Assigned for a different source Provider name.

This decision narrows ADR 0092 for explicit XLSX rows: valid AI candidates may still be kept while invalid AI candidates are dropped for ambiguous extraction, but an explicit structured row is not silently omitted merely because AI failed to return it. It refines ADR 0113 without removing worksheet profiling or chunked fallback extraction, and it preserves ADR 0111 by creating deterministic candidates only when each required concept has a complete two-field category suggestion. When a source path contains more than one slash, Habi retains the first segment as the Top-Level Category and the remaining source text as the single subcategory value rather than duplicating the full path into both fields.

Processing Job diagnostics will retain raw AI candidate counts and separately report source-grounded candidate counts and AI candidates replaced by source-grounded rows. Automated coverage uses the injected fake AI adapter required by ADR 0082 and exercises the public upload, Processing Job, and Review Batch behavior.
