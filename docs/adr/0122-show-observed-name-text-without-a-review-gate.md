# Show Observed Source Text Without A Review Gate

Free-form Manual Source Entry and XLSX Extracted Candidates will keep the model's normalized or Project-Memory-matched Material, Service, and external Provider names as the primary names in Candidate Detail while also displaying the exact Observed Name Text or Observed Provider Text that grounds each value in the source. The observed text is immutable, read-only provenance; reviewers edit proposed candidate names, never source wording. An Internal Provider displays `Internal` together with the observed wording that supports the state, such as `our crew` or an exact Contractor Assigned name; an Unknown Provider has neither a name nor observed provider text. Observed text introduces no separate `Needs decision` state, reviewer choice, or Taxonomy Gate. This lets reviewers see that source wording such as `Eagle Portland` became the proposed name `Eagle Portland Cement` without weakening useful normalization or adding routine review friction, and it extends the same audit vocabulary across free-form and XLSX inputs.
