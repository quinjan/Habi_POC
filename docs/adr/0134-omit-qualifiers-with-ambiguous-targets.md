# Omit Qualifiers With Ambiguous Targets

GPT-5.5 free-form extraction will propose an Evidence Annotation only when the source clearly identifies exactly one target or explicitly identifies multiple targets that can receive separate proposals under ADR 0123. A qualifier such as `One-year warranty included` is omitted when the source does not establish whether it applies to a Material, Service, Provider, or the complete Purchase Line; Habi will not default ambiguous qualifier targeting to Purchase Line. Purchase Line remains the target only for wording that clearly describes transaction-wide terms, such as an explicit payment obligation, included delivery for the purchase, quote validity, or a warranty expressly covering the complete supply-and-install transaction.

Omitting an ambiguous qualifier is deliberate policy, not a silently dropped valid annotation under ADR 0133, and does not invalidate an otherwise grounded candidate. Evidence Annotations never create Purchase Lines: if other source text supports a Purchase Line, the candidate proceeds without the ambiguous annotation; if the source contains only an ambiguous qualifier and no purchasing fact, the model returns zero candidates and follows ADR 0127's optional zero-candidate confirmation behavior.
